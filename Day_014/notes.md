# Day 14 – Functional Programming

## What I Learned Today
- What functional programming means
- How map(), filter(), and reduce() work
- What higher-order functions are
- What closures are and how they work

## Key Concepts
- Functional programming works with functions instead of changing data
- Original data is not modified
- map() applies a function to every item
- filter() keeps items that pass a condition
- reduce() combines values into one result
- Higher-order functions accept or return functions
- Closures remember values from outer functions

## Why This Matters
- Makes code cleaner and safer
- Avoids unnecessary data changes
- Commonly used in real-world Python programs

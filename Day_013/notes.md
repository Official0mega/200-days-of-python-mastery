# Day 13 – Regular Expressions (re)

## What I Learned Today
- What regular expressions are
- How to use match(), search(), findall(), and sub()
- How meta-characters work
- How to use groups
- Why raw strings are important

## Key Concepts
- Regex is used to find, check, and replace text using patterns
- match() checks only the start of a string
- search() checks anywhere in the string
- findall() returns all matches as a list
- sub() replaces matched text
- Meta-characters have special meanings
- Groups use ( ) to extract parts of a match
- Raw strings use r"" and should always be used in regex

## Why This Matters
- Helps validate input
- Finds patterns quickly
- Commonly used in real-world programs
